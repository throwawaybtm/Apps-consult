Data tamu dijaga

Diperiksa di server

Setiap fungsi admin diperiksa di server, bukan hanya di tampilan. Jika ragu, aplikasi menolak.

Tidak saling menimpa

Setiap penyimpanan memakai kunci dan pemeriksaan versi: jika data sudah diubah admin lain, layar lama diminta memuat ulang.

Nomor PIC tidak bocor

Formulir publik tidak pernah menerima nomor WhatsApp PIC atau tautan dokumen internal.

Rahasia di tempatnya

Token WhatsApp disimpan di pengaturan server, bukan di kode. Dokumen berada di folder Drive milik Dinas.

Aplikasi ini memegang nama dan nomor WhatsApp tamu, jadi pengamanannya penting. Pemeriksaan dilakukan di server. Dua admin yang bekerja bersamaan tidak akan saling menimpa. Formulir publik tidak menerima data internal. Kunci WhatsApp tidak disimpan di kode.
